# DAY 5: Complete Blog Platform

# WHAT I BUILT:
# Full MERN Blog Application with:
- User authentication (register/login/logout)
- Create, read, update, delete posts
- Image uploads for posts
- Search functionality
- Pagination
- Ownership-based permissions

# PAGES CREATED:
- PostsPage: List all posts with search and pagination
- SinglePostPage: View single post
- CreatePostPage: Create new post with image
- EditPostPage: Edit own posts
- DashboardPage: Protected user dashboard

# FEATURES:
- Only authors can edit/delete their posts
- Images stored in uploads folder
- Search debounced for
